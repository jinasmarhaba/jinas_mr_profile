PREVIEW LOCALLY
1. Extract this ZIP folder.

BEFORE PUBLISHING
- Replace the LinkedIn and Instagram placeholder URLs in data.js with your exact profile links.
- Confirm you want your phone number publicly visible before sharing the website.
- This ZIP is a website package; it is not yet published online.

FREE HOSTING
You can publish the folder with a free static hosting service such as GitHub Pages. Keep index.html, style.css, data.js, and the photos folder together.

To add more photos later, put them in the photos folder and update index.html.
